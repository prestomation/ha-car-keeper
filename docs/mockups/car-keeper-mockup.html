Car Keeper mockup

Car Keeper is a planned companion of Home Keeper for car maintenance. This page shows how it can look: a Cars tab in the Home Keeper panel for admins, and a dashboard card for all users. The frames copy the tokens and the components of the Home Keeper panel and the Library tab. The data is an example.

Try it: type an odometer value in screen 2, log a service in screen 4, change the unit or the frame theme in the bar below. The frames share 1 state. Orange markers 1 point to the parts that the legend below each screen explains.
