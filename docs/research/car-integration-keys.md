# Car integration entity keys

`key` of the entity description. When the translation key is different, the cell says so. "Read
at" is the commit or version of the source that I read. The raw records, with the platform, the
unit and a note for each key, are in [data/](data/).

A row with "not verified" comes from docs or memory, not from source code.
